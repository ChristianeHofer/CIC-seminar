This cheatsheet provides an overview for quick seasonal adjustments in RStudio. It can be seen as a step-by-step guide providing the basic functions needed.

First Step: Before the seasonal adjustment

Before the seasonal adjustment, the data that we want to analyze and adjust, needs to be loaded and prepared.

The dsa() functions requires daily data in the xts format.

Second Step: Specifications of seasonal adjustment

Calendar regressors

The regressors used for the calendar adjustment need to be provided in two sets:

  1. Regressors for the regarima model, with the same number of observations as the time series excluding February, 29.
  2. Same regressors for the forecast, again excluding February, 29. The number of observations needs to be equal to h (usually 365)

Whether a calendar regressor is significant or not can be seen in the regression output (regarima).
Further, one should think of a plausible economic explanation for the effect of a calendar regressor.

Seasonal and calendar adjustment of the series

The dsa-function has several arguments allowing for an individual specification of the seasonal adjustment, for a full overview see ?dsa (in the console).

Function Description
dsa(series,
log = TRUE,
s.window1 = 53,
s.window2 = 53,
s.window3 = 13,
fourier_number = 24)		 Seasonally adjust daily time series
library(dsa)


The regressor argument should be set to the determined calendar regressors and forecast_regressors to the determined forecast calendar regressors.

The order of the model can be determined automatically. The s.window option can be changed based on the SI-ratios from output().

Example 1

This example uses a simple, simulated series to illustrate the basic steps of daily seasonal adjustment.

### Simulate a series
set.seed(259)

series <- dsa::daily_sim(n=365*5+1,
                         week_effect = 3,
                         month_effect = 0.1,
                         year_effect = 10,
                         year_cycles = 1)

add_calendar <- tssim::sim_calendar(n = 365*5+1, 
                                    freq = 365,
                                    which = c("EasterMonday",
                                              "Pentecost"),
                                    effect_size = 30,
                                    start = "2005-01-01",
                                    center = FALSE)
                                    
series <- series$original * add_calendar

plot(series)


Per definition of the simulation, the series contains calendar effects. In order to include them in the regression, a variable containing all calendar regressors needs to be specified.

library(dsa)

AllHol1 <- merge(holidays$Pentecost,
                 holidays$EasterSunday,
                 holidays$EasterMonday)
AllHolUse1 <- multi_xts2ts(AllHol1["2005/2009"])
AllHolForecast1 <- multi_xts2ts(AllHol1["2010"], short=TRUE)


Daily seasonal adjustment using the previously specified calendar regressors as well as dsa() default specifications.

result1 <- dsa(series,
                   Log = T,
                   s.window1 = 13,
                   s.window2 = NULL,
                   s.window3 = 13,
                   fourier_number = 1,
                   model = c(0,1,1),
                   regressor=AllHolUse1, 
                   forecast_regressor = AllHolForecast1)


Plotting the results of the daily seasonal adjustment. Note that the results include a forecast.

xtsplot(result1$output[,2:1])


Check the fit of the model graphically:

print(result1$reg)

Of special interest are the coefficients and their standard errors.
If
                   |coefficient/s.e.| > 1.96,
then the regressor is significant at the 5%-level. Here the EasterSunday-regressor is not significant, while the other regressors are significant. Therefore, the EasterSunday-regressor should be removed from the model.

AllHol <- merge(holidays$Pentecost,
                holidays$EasterMonday)
AllHolUse <- multi_xts2ts(AllHol["2005/2009"])
AllHolForecast <- multi_xts2ts(AllHol["2010"], short=TRUE)


Re-run the daily seasonal adjustment

result <- dsa(series,
                   Log = T,
                   s.window1 = 13,
                   s.window2 = NULL,
                   s.window3 = 13,
                   fourier_number = 1,
                   model = c(0,1,1),
                   regressor=AllHolUse, 
                   forecast_regressor = AllHolForecast)
